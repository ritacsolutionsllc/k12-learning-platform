# Decision 0001: Product wedge

## Wedge

Build a K-12 learning platform focused exclusively on math for grades 6-8.

## Scope boundary

The project scope is frozen for 90 days. Do not expand to other subjects or
grades, or add features identified as out of scope in the project instructions.

This record captures only the wedge and freeze stated in the project
instructions; it does not introduce additional product, customer, or
implementation decisions.
